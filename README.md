# fNIRSmanufacturing
MATLAB pipeline for prefrontal fNIRS functional connectivity during haptic-enabled virtual assembly training (N=30; rest, low- and high-complexity tasks). Homer3/SNIRF preprocessing, Fisher z matrices with FDR control, intra- and inter-hemispheric RM-ANOVA with Tukey-Kramer post hoc, network graph rendering and 900-dpi publication-ready figures.
